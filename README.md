## Overview

DiTz Store Portfolio is a modern single-page portfolio created to introduce the DiTz Store brand, showcase website-development services, display selected work, and connect potential clients directly with the owner.

The experience combines a premium visual direction with interactive elements while remaining responsive across mobile and desktop devices.

## Main Features

- Animated welcome experience with custom audio
- Premium dark and light theme system
- Interactive 3D visual elements powered by Three.js
- Service and portfolio presentation sections
- Website package and pricing information
- Public-facing contact and social links
- Responsive layout for mobile, tablet, and desktop
- Modern typography and consistent visual branding

## Run Locally

Clone the repository and open `index.html` using a local development server.

```bash
git clone https://github.com/sunandarradit3-maker/ditz-store-portofolio.git
cd ditz-store-portofolio
```

A simple local server can be started with:

```bash
npx serve .
```
